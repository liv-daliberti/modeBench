# Release scope — 0.1.0

This initial standalone release contains the five-domain benchmark package, versioned prompt rendering, PCMD and support reporting, saved-response CLI, 72 frozen data splits, source attribution, basic-domain construction tools, 375-cell saved-key reproduction, and regression tests.

The benchmark installs independently of the original research checkout and the Re:Max/Re:Dr training stack. See [validation](VALIDATION.md) for checks actually completed.

## Known gaps and follow-up work

- Verifier equivalence to every historical experiment's frozen runtime has not been independently established beyond retained regression fixtures. The original extraction included working-tree changes; source-file hashes are preserved.
- The separately admitted neutral-Python Level 3 dataset is not included. Bundled data and the default prompt condition retain the historical interface.
- Full Level 2–5 construction, fitting, confirmation, and admission workflows remain to be consolidated. Frozen datasets are included; basic-domain generators alone do not reconstruct those workflows.
- Hosted-provider collection and complete raw-response archives are not included. The evaluator accepts saved responses, while retained base-grid analysis operates on verified keys.
- Dataset source terms retain the original export's attribution record; no new blanket dataset license has been assigned.
- Final scientific citation metadata and additional experiment-specific reproduction packages remain follow-up work.

Level 4 MathIR's unmatched status is a protocol limitation, not a software installation issue. See [datasets](docs/datasets.md#level-admission).

Historical machine paths in provenance files are identifiers, not runtime dependencies. Exploratory maze, interactive robotics, constructive-code, and SATA work remain outside this benchmark release.
